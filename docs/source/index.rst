LLM-ABBA documentation
======================

LLM-ABBA is a Python library for symbolic time-series analysis with large language models. It represents numerical signals as sequences of symbols for reconstruction, classification, regression, and forecasting.

Start with the CPU example in :doc:`getting-started` to encode and reconstruct a signal. For fine-tuning, choose the tutorial that matches your target. The :doc:`api` lists constructors, methods, and examples grouped by what they do.
